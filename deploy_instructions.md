# Deployment Instructions for Mikostraj Personal Website

## Quick Deploy (Drag & Drop)
1. Go to https://netlify.com
2. Login or create account
3. Drag this entire folder to the "Drag and drop" area
4. Wait for deployment (usually 1-2 minutes)
5. Click "Site settings" to rename to "mikolaj-personal"

## CLI Deploy (Advanced)
```bash
# Login to Netlify
netlify login

# Deploy from this folder
netlify deploy --prod --dir=. --site=mikolaj-personal
```
